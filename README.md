# Maths Entry Practice

A self-contained web app for practising a university foundation-year maths entry test.

**Unofficial.** Independent revision material, written from scratch. Not produced by,
endorsed by, or affiliated with any university, and not a copy of any real exam paper.

## What it is

Two steps, gated:

1. **Training set — 60 questions.** Marked question by question with the working shown.
   Unlimited attempts, reshuffled each run. Reach 80% to unlock step 2.
2. **The test — 40 different questions.** 1 hour 30 on the clock, no feedback until you
   submit, auto-submits at zero. Pass mark set at 60%. Every answer and explanation is
   shown afterwards.

Topics: number and arithmetic, algebra basics, graphs and charts, shape and measures,
statistics and probability, money and everyday maths.

## Running it

`index.html` is a single self-contained file. Open it in any browser — no server, no build
step, no dependencies. It works offline; only the web fonts need a connection, and there
are fallbacks for them.

Progress is stored in the browser, so the unlock does not follow you to another device.
